# 三站凭证

当前匿名阅读不需要饼干。账号注册、验证码、领取和导出请由用户在对应站点完成；不要把饼干发到对话里。站点间不能共用身份。

## 岛民岛

启动器使用专用配置目录 `.local/islander-poster-girl/config`，不自动复用 TUI 的个人饼干。先编译 `make build`，然后从仓库根目录用隐藏输入导入专用身份：

```sh
XDG_CONFIG_HOME="$PWD/.local/islander-poster-girl/config" ./bin/islander cookie import mascot
```

具体存储选项看 `cookie import --help`；默认 keyring，文件后端需明确选择且文件权限应为 0600。发布时指定 `--cookie mascot`。`R5RCGeZ` 是开发员的显示 ID，不是要导入的 token，也不应借用他的身份给岛民娘发言。

## X 岛

本机可在资料目录的 `.env` 中保存 `NMBXD_USERHASH`，值保留原有百分号编码；文件权限设为 0600，已被 Git 忽略。当前启动器和匿名读取工具不自动加载 `.env`；保存凭证不等于已验证身份或启用发布。不要把这个文件复制进启动提示词或会话日志。

从 [用户系统](https://www.nmbxd1.com/Member) 注册/登录，在开放时领取饼干并「应用」。浏览器开发工具中查看该站 Cookie 的 `userhash` 值；它是敏感鉴权数据，**不是页面上的七位 `user_hash`**。不要导出整个浏览器 Cookie 仓库，也不需要提供用户系统密码。

若以后接入客户端，应通过隐藏输入写入仓库外或 `.local/` 内的 0600 凭证文件，再由程序构造 `Cookie: userhash=…`。保留浏览器存储的编码形式，避免双重 URL 编码。网页发布域 `www.nmbxd1.com` 与 API 域 `api.nmb.best` 是不同主机；授权发送的主机需要显式列举，不向图片 CDN 或跨域重定向附带凭证。当前 `read_forum.py` 不读取或传送饼干。

## BOG 岛

在 [设置页](https://bog.ac/page/set) 领取、兑换或导入。页面说明格式是 **八位显示 ID + `#` + 三十二位密钥**；领取是否开放以当时页面为准。

网页脚本使用 `bog_master` 保存主饼干，`bog_sel` 表示选中的显示 ID，`bog_list` 管理影武者。主饼干可管理影武者，属于完整账户凭证。`/api2/userinfo` 使用拆开的 `cookie` 与 `code` 字段；这不意味着所有 `/api2` 路由都已核对。

用户可为岛民娘准备独立身份，保存到本机受限文件；后续接入前明确所选显示身份。不要随便调用生成影武者、删饼干、兑换、签到或消耗积分的接口。当前辅助程序不导入 BOG 饼干，配置文件格式留待实际写入适配确定，不提供会被误认为已生效的虚假配置。

## 当前发布状态

岛民岛已有 CLI 发布流程；外站目前是匿名读取 + 已核对的网页表单资料。尚未配置和验证外站发布，`participate` 模式也不能把这部分视为已完成。资料目录可提交；真实凭证、会话、草稿和日志仅留 `.local/`，不提交、不推送。
