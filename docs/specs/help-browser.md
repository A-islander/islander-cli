# 可浏览的 TUI 帮助

按 `?` 打开统一的命令帮助，替代在线、离线两套长文本弹窗。每个操作独占一行，显示按键与简短名称；执行同一操作的多个按键合并显示，编辑和原图页面的专用按键带场景前缀。

- `>` 和整行底色标记选中项。↑↓ / j k 选择，Enter 查看详细说明，不执行命令。
- 详情说明适用页面、操作效果、确认流程与返回方式。Esc 从详情返回列表并保留选择及列表位置，再按关闭帮助；q、右键与点击外部也逐层返回。
- 列表和详情均可滚动，支持 PgUp / PgDn、Home / End；尺寸改变后重新限制可见区域，最小 44×16 终端也可访问所有条目。
- 鼠标滚轮在帮助弹窗内移动选择或滚动详情，点击列表行直接进入该项说明。鼠标事件不穿透到背后的帖子。
- 查看帮助时，普通命令键不会触发发帖、删除、布局或主题切换。Ctrl+C 仍可退出。
- 根据当前站点能力显示发串、回复、我的内容、SAGE 与管理命令；离线演示仅显示可用的浏览操作。
- 普通布局、Agent 布局与 el 主题共用同一帮助内容。关闭后保留串、选中楼层及阅读位置。

实现使用独立的帮助选择、列表起点及详情滚动状态，不复用正文 viewport 或操作菜单。渲染与鼠标命中共用弹窗尺寸计算；列表每行截断，详情按终端单元格宽度换行。

验证覆盖列表首尾、详情滚动与返回、44×16 窗口、窗口变大后的滚动限制、鼠标点击与滚轮、命令隔离及各站点能力过滤。
