# 终端主题适配

## 需求

使用 Ghostty 等终端的自定义主题时，允许 TUI 与终端的色调协调，避免固定蓝灰背景与终端割裂，也避免把高饱和度 ANSI 色直接用于大面积正文。保留原有论坛主题和 Agent 模拟布局。

## 使用方式

- `islander tui --theme el`：柔和跟随终端；`--theme islander` 使用原主题。
- F7 在原主题和 el 主题之间切换。普通界面底部与帮助页显示提示；Agent 页保留精简布局，F7 同样有效。
- F7 将主题名保存到根数据目录的 `preferences.json`，字段为 `theme`。不覆盖站点、Agent 模式和其他偏好；演示模式不保存。
- 启动优先级：显式 `--theme` > 已保存主题 > 原主题。命令行参数仅覆盖本次启动，F7 才保存选择。切岛保留当前主题。

## 颜色与渲染

使用 Bubble Tea 的 `RequestForegroundColor` / `RequestBackgroundColor` 异步查询终端（OSC 10/11）。只读取颜色，不修改终端配置或终端默认色。当前进程保存返回的色值，每次启动重新查询，避免在不同终端之间沿用错误的颜色。进入终端主题时重新查询，也接收终端主动发送的颜色更新。

颜色查询与论坛加载并行。两个颜色都返回后才启用适配；没有响应或只返回一项时继续显示原主题，启动不等待超时。tmux 或远程终端如果拦截颜色查询，也按此方式回退。此功能不需要终端支持图片。

终端背景保持原色；高饱和度前景色与中性色混合，生成柔和正文。正文尽量达到 7:1 对比度，背景限制无法达到时选择对比度更高的黑色或白色。选中底色从背景与正文派生，正文和次要文字在普通背景、选中背景上均保持至少 4.5:1 对比度。对中等亮度背景按需反向调整选中底色，避免选中后文字变得难读。对比度用于保证可读性，不代表所有显示器上的主观舒适度。

最终画布统一转换正文、空白、边框、选中项及弹窗的语义颜色，避免文字周围出现不同底色。编辑器与单行输入框使用同一组语义颜色。Agent 模式的命令语法颜色和 Working 动画也调整到协调的色调，保留布局与动画。

Kitty 占位符的前景色编码图片 ID，必须保持原样；字符块图片的前景色和背景色是真实像素，也不得转换。图片下载、缓存及阅读位置不受主题切换影响。

## 验证

- 测试橙黑、浅色、灰黑以及中等亮度背景的正文与选中项对比度。
- 检查普通和 Agent 画布的完整背景、选中高亮，以及图片 RGB / Kitty ID 的保留。
- 检查无颜色响应的回退，以及异步颜色响应不会触发请求或改变阅读位置。
- 检查偏好恢复、显式参数优先级，以及主题与 Agent 模式的保存互不覆盖。
- PTY 模拟终端颜色查询响应，验证真实可执行文件的启动、切换和退出。
