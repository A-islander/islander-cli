# 串内小图和 tmux 图片透传

## 需求与交互

岛民岛、X 岛、BOG 共用 `Post.Media()`，在主串和每条回复正文下显示小图，原位展开的引用也采用同一布局。多张图片逐张排列，默认每张最多 40 列、6 行，保持长宽比；可用缩放键调整。视频、音频继续保留附件入口，不尝试图片解码。

`a` 仍打开选中楼层或引用的原图窗口；左右切换、外部打开、下载和字符预览按键保持可用。串内预览沿用 `--images auto|kitty|blocks|off`：默认在支持时使用 Kitty Unicode 占位图片，否则只显示 `a 加载附件` 提示，不自动请求图片，也不在正文里显示字符图。`blocks` 模式同样仅手动打开附件后显示字符图；`off` 关闭所有图片加载。

确认终端支持图片后，每张小图在当前缩放级别下从未加载、加载中、完成到失败都保留相同高度（默认 6 行图片区域和 1 行操作提示），异步加载不会改变正文位置。小图属于该楼层的阅读范围，`j/k` 必须读完正文和小图再进入下一楼；滚动、自动翻页、跳页不额外改变锚点。

列表分栏的串预览也支持小图：主楼及最多五条回复的首张图片放在正文右侧，默认沿用正文 1–3 行的预算，不把五条短回复挤走。窄屏未展示串预览时不加载预览图片。预览页按 `a` 可查看当前主楼与预览回复的全部附件，左右切换；不把预览回复写入完整阅读状态。

`+` / `-` 调整小图大小，`=` 等同放大，串预览与正文共用本次运行的大小设置（不写入 JSON）。放大预览时图片可以占据更多行，完整串仍可按 Enter 打开。缩放保留当前楼层和相对阅读位置，复用已解码图片，按新尺寸创建独立原生放置；编辑器内不截获这些字符；原图窗口使用独立的缩放设置。

原图窗口支持 `+` / `=` 放大、`-` 缩小、`0` 适应窗口，百分比以适应窗口为 100%。放大超出窗口时裁剪显示，`Shift + 方向键` 平移，`↑↓` 也可上下移动，普通左右键仍切换附件。缩放复用已解码原图，原生模式只更新 Kitty 放置尺寸；字符预览只采样可见部分。原生裁剪保留完整图像坐标对应的 Unicode 附加符，不重新从零编号。切换附件重置缩放和偏移，返回仍保留阅读位置。

终端能力尚未确定时只发协议查询，不发图片 HTTP 请求；确认后才生成图片布局并加载。能力返回导致行数改变时，按原楼层和相对行偏移恢复阅读锚点。

## 加载与资源生命周期

- 优先请求适配器提供的 `thumbnailUrl`；不存在或请求失败时尝试原图一次。只用不携带饼干的附件 HTTP 客户端。
- 串预览只加载可见区域的图片；进入串后加载阅读视口及前后一屏内的图片。并发最多 2 个请求，保留最多 16 个解码缓存条目，按最近使用情况淘汰屏幕附近范围外的条目。
- 下载上限 20 MB，解码前限制 3200 万像素，小图缩至最多 320 × 192 像素。网络超时 30 秒；离开预加载范围取消尚未完成的请求；错误不循环重试，用户可按 `a` 查看和重试原图。
- 缓存只在内存中；切串、切岛、退出阅读和关闭预览时清理相应资源。缩放后的不同布局有独立缓存键；过时下载、编码和协议响应不能恢复旧图片。
- 小图和原图窗口各自分配图片 ID，删除只针对本程序创建的 ID。Unicode 占位符随正文一起裁剪和滚动，遮挡它的弹窗不留下独立浮动图层。

## tmux

普通终端保留能力查询与上传确认，超时保留附件文字提示；附件弹窗仍可降级字符预览。tmux 内每个 Kitty APC 命令分别使用 `ESC Ptmux; ... ESC \\` 包装，内部 ESC 加倍；分块上传也逐块包装，避免一张大图成为超大的 DCS。删除、原图缩放同样透传。

启动时读取当前 `TMUX_PANE` 对应的 tmux 客户端终端类型。自动模式识别 Ghostty / Kitty；`--images kitty` 可显式指定其他兼容终端。tmux 的图形响应无法可靠回传，因此使用 `q=2` 静默上传，不依赖 ACK；上传输出后再显示 Unicode 占位符。未知终端、无法读取或设置窗格选项时保持附件文字提示。

仅在需要图片透传时临时为当前窗格设置 `allow-passthrough on`，不修改全局或磁盘配置。退出时恢复原显式值或继承关系；用户在运行中改成不同值时保留该修改。原本已启用 `on/all` 的窗格不改动。进程被强制终止时无法保证执行退出恢复，可手动 `tmux set-option -pu allow-passthrough` 恢复继承。

本实现处理一层 tmux。嵌套 tmux、不支持 Unicode 占位符的终端或自行关闭图片功能的终端可用 `--images blocks`；通过名称识别的 tmux 静默模式不保证外层终端实际绘图成功。

协议参考：[Kitty Unicode placeholders](https://sw.kovidgoyal.net/kitty/graphics-protocol/#unicode-placeholders)、[tmux 手册](https://github.com/tmux/tmux/blob/master/tmux.1)。

## 验证

单元测试覆盖三岛串预览及引用布局、五条回复文字、未确认支持时不下载、手动 a 加载回复附件、缩放缓存复用与编辑输入、固定行数、宽度裁剪、长回复不跳过、缓存与并发上限、关闭后过时结果、原生图片颜色 ID、协议超时、静默上传，以及窗格配置的设置和恢复。另用本地论坛/图片 HTTP fixture、PTY 和独立 tmux 服务验证自动识别、透传输出、Unicode 图片字符、小图优先、`a` 请求原图及退出清理；不向真实论坛发帖。
