# TUI 图片缓存

串内缩略图原先只有当前串的内存缓存，关闭原图会释放解码结果，换串或重启后需要重新下载。新增磁盘缓存供缩略图和原图查看共用，独立于终端图片占位与论坛帖子缓存。

## 数据与路径

- 保存成功解码的源图片字节，按完整 URL 的 SHA-256 命名为 `.img` 文件。域名、路径和查询参数均参与区分，不把链接或饼干写入索引。缩略图 URL 与原图 URL 不同则分别下载；相同 URL 的源文件同时支持小尺寸及原图解码。
- 默认目录采用 Go `os.UserCacheDir()` 下的 `islander/images`：Linux 通常为 `~/.cache/islander/images`，macOS 为 `~/Library/Caches/islander/images`，Windows 为 `%LOCALAPPDATA%\islander\images`。指定 `--data-dir` 时改为该目录下的 `cache/images`；三岛共用同一缓存对象，避免切岛丢失。
- 不改变 preferences.json、浏览历史、身份或草稿格式。目录和临时文件按当前平台支持创建为 0700 / 0600。

## 生命周期

- 首次加载仍使用无 Cookie、无 Authorization 的媒体请求，保留 URL、重定向、20 MB 下载上限及 3200 万像素解码限制。非图片、损坏内容、失败响应不缓存。
- 命中后验证并解码缓存，更新最近使用时间；无需联网。损坏或 30 天未使用的条目视作未命中。原图页 `r` / Enter 绕过缓存重新获取，成功后替换，失败保留原有可用文件。
- 同进程同一 URL 串行加载并复用先完成的缓存。取消缩略图请求不会取消正在等待的原图请求；等待者可以取消自身请求，空闲的 URL 锁立即释放。
- 写入使用同目录临时文件和重命名。多进程用目录锁协调写入及清理，不持锁执行网络下载。缓存不可用或写入竞争超时不影响已经下载成功的图片显示。
- 每次成功写入清理 30 天未使用的图片，再按最近使用时间淘汰，限制为 256 MiB 且最多 1024 张。终端内已有解码图像继续沿用原有内存上限与释放逻辑。
- 删除缓存目录即可清空。外部浏览器打开及显式下载仍沿用原来的行为；关闭 TUI、换串、切岛只清理终端占位和内存，不删除磁盘图片。

## 验证

覆盖缩略图与原图同 URL 复用且不损失原图尺寸、不同查询参数隔离、重建缓存对象后的离线读取、并发去重与取消隔离、损坏和过期修复、强制刷新失败保留旧文件、容量和数量淘汰、不可写目录降级。TUI 测试覆盖打开原图、重开、r 刷新与切岛保留缓存对象。
