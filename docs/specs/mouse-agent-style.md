# 鼠标浏览与 Agent 模拟切换

## 交互

- 左侧标题行单击进入阅读；无标题卡片的首行正文按标题处理。其他卡片行单击选中，400 ms 内在同一位置双击进入阅读。卡片按有标题四行、无标题三行计算命中位置，间隔行不选中。Agent 列表的标题、模拟读取文字及正文摘要均可单击进入阅读。
- 右侧正文单击选中对应楼层，右键打开该楼层的引用、回复、附件等操作。嵌套引用按实际渲染路径定位。菜单打开后再次右键或左键点击菜单外部关闭，使用 Esc 相同的取消逻辑；关闭事件不继续触发底层标题、板块或模式按钮，点击菜单边框和内部留白不关闭。
- `Ctrl+[` / `Ctrl+]` 按当前板块顺序切换，包含时间线，到边界停止；只在非忙碌的浏览页响应，两种布局通用，复用板块选择与第一页加载。依赖终端的按键消歧义支持，不能区分 Ctrl+[ 与 Esc 的终端仍可用 b 菜单。
- 图片浏览弹窗内滚轮向上放大、向下缩小，复用 +/- 的缩放范围和渲染，不重新下载；弹窗外不缩放，串内滚轮仍滚动正文。
- 滚轮操作指针所在栏；串内滚轮复用 j/k 的逐楼导航，普通回复居中，头尾按内容边界停靠；超过一屏的回复和嵌套引用先逐行读完再换楼。正文读到边界复用已有自动翻页逻辑。模态菜单内滚轮移动菜单选项。
- 板块标签、我的内容、菜单项、页码、引用提示和附件支持点击。缩略图点击打开对应原图，附件文字打开该楼层首个附件。
- 不实现正文拖选；带 Shift 等修饰键的鼠标事件不执行浏览动作。

## Agent 模拟

论坛顶部提供 `F6 Agent模拟切换`，也可用 F6。模拟模式使用独立布局，隐藏论坛品牌、标语、板块标签、面板边框、页码栏和常驻快捷键提示。顶部显示 `>_ Codex` 与通用文件读取记录；串阅读页在顶部最右侧固定显示 `exit`，与 Codex 标识同一行、同字体样式，无边框和独立底色，不增加正文占用行。整块按钮可点击，直接返回列表并保留列表与串内阅读位置；总览页隐藏，弹窗或编辑期间不触发返回。浏览隐藏作者、串号、楼层和时间；正文中的 No. / >> 引用编号显示为 `[reference]`，真实正文和引用目标保持原样；使用深灰背景与白灰文字，选中楼层使用浅一级灰底。底部仅保留 `›` 输入区和 `gpt-6-astra high · ~/Develope/islander · Main [default]` 状态行。状态文字是固定的模拟装饰，不执行代码、不调用模型或读取本机 Git。F6 返回论坛；b、g 等既有键盘入口保留，隐藏按钮不接受点击。

读取中的串下方显示回复输入区，点击或按 r 编辑，R 引用选中楼层。Enter 插入换行，Ctrl+P进入现有发布预览，只有预览页 Enter 才执行发送。复用饼干检查、身份绑定、草稿与编辑历史、F3 颜文字、Ctrl+A 文件选择及各站发送实现。无饼干时打开带提示的饼干管理窗口。发新串 c 仍使用现有编辑窗口。

F6 可在正文编辑时切换，正文与光标保留，编辑区随布局变为底部输入区或原编辑窗口。菜单、发送确认及忙碌状态不切换。布局标志跨站切换沿用，并在切换时立即保存到根目录 `preferences.json` 的 `agentSimulation`。切换布局保留列表或阅读焦点；下次启动恢复该模式并停在列表，第一条仅后台预加载，点击后才进入阅读；缺少字段时默认论坛布局。写入加锁并合并现有站点设置，损坏或未知版本文件不覆盖。

## 实现约束

- 两种布局复用线程数据、完整正文渲染、引用树、附件与分页状态。切换不重新请求帖子。
- 鼠标进入右栏优先采用当前已加载页面或完整页缓存；缓存未就绪时提示 Enter 阅读。
- 布局切换按顶部可见楼层键与楼内偏移恢复视口，正文宽度变化时重新换行。
- 模拟页正文从第 7 行开始，下方固定输入区与状态行；正文和列表复用各自的布局坐标函数进行鼠标命中，不沿用隐藏的论坛顶栏坐标。
- 通过最终画布将论坛主题色映射为中性色，包括弹窗与空白单元格，保留图片占位符的颜色编码。输入框取消默认光标行的黑色背景，避免 Ghostty 中出现不一致的底色。
- 普通翻页/读取后的论坛导航提示在模拟页隐藏；阅读期间的操作反馈替换顶部装饰性读取记录，保留 Working 行；编辑期间的反馈显示在输入区上方。
- 底部回复区占用阅读高度；窗口变化后同时更新正文视口与编辑器尺寸。

## 验证

单元测试覆盖混合卡片高度的单击/双击、右栏缓存选楼、右键目标、滚轮跟随指针、标签和菜单命中、引用展开收起、附件归属、F6 保持页码与选中楼层，以及 44×16 至 120×36 的布局和编辑切换。回复测试仅向本地模拟服务提交，检查 Enter 换行、草稿保存重开、预览不发送和确认后的目标串及饼干。

## 模拟工具输出

以会话随机种子和站点、帖子的稳定键选择插入位置与模板：主楼后插入一段，其他发言约三分之一概率插入。刷新、选中楼层、窗口变化、追加分页不会重新抽取既有帖子的模板。模板使用预置的 vet、build、Python 测试输出与示例校验和；纯显示，不启动进程、不调用接口，也不表示真实检查结果。

工具块纳入楼内滚动高度，长内容仍可逐行读完；命中范围仅覆盖真实发言，工具块不响应引用或右键等帖子操作。模拟浏览隐藏元信息，但编辑器与发布确认仍使用真实引用及目标串，切回论坛恢复原始显示。

## 命令配色与 Working 动画

命令块使用显示层词法着色：命令名淡绿加粗，参数和关键字淡紫，路径淡蓝，字符串暖黄，数字与布尔值暖橙；树状线条及普通输出为灰色。先着色、后按终端列宽换行，折行补齐树状前缀。最终主题映射保留这些语义颜色。

阅读计时在进入串时开始，普通布局切换到模拟布局时沿用已读时长；换串、换身份或退出再进入重新开始。模拟阅读区上方显示 `Working (4m 31s • esc to interrupt)`，80 ms 一帧，白色高光带从 Working 左侧扫向右侧并循环。Esc 沿用原有返回/取消语义，退出阅读后计时清除。编辑和弹窗中暂停动画刷新，但保持本次阅读起始时间，关闭后显示完整经过时长。

每次最多挂一个动画计时器；切回论坛、退出阅读、打开弹窗或缩到最小尺寸以下时停止动画刷新，旧帧通过唯一编号丢弃。动画帧只更新显示时间，不进入请求、草稿保存、图片加载或正文重排流程。

## 逐楼滚动动画

滚轮与 j/k、上下键使用相同的居中规则。普通回复完整显示并尽量居中；头尾按实际帖子范围限制位置，超长回复向下从开头进入、向上从尾部进入，逐行阅读。PgUp/PgDn、空格和 n/p 保留快速滚动与直接跳楼语义。

跨多行的视口变化使用约 150 ms 缓出动画。导航和历史保存目标位置，渲染时复制视口显示中间帧；动画帧不触发正文重排、接口请求、图片下载或历史写入。连续滚动从当前显示位置衔接，旧帧通过编号丢弃。鼠标点击先采用可见帧的位置，再执行楼层和附件命中；返回列表、切换布局、缩放窗口和打开弹窗取消动画。两种布局通用。
