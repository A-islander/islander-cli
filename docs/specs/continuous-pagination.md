# 连续加载与页码跳转

日期：2026-09-07。分支 `feat/reader-scroll-kaomoji`，首发版本 v0.0.4。

## Flutter 参考

对照当前 `islander-flutter/lib/features/forum/forum_screen.dart` 的 `_onScroll`、`_loadMore`、`_loadPrevious`，以及 `page_jump_sheet.dart`。Flutter 向下接近底部时追加下一页，向上接近顶部时补入上一页，按帖子编号去重并保留已有内容；失败后暂停该方向自动加载。跳页窗口显示当前页、已知总页数，输入从 1 开始的页码，提供首页、已知末页和最新回复。

TUI 沿用连续加载和编号去重，但以继续越过当前内容边界的按键/滚轮操作触发请求，以免长回复尚未读完就被下一页取代。

## TUI 行为

- 列表 `j/↓` 到最后一项后继续向下，自动接上下一页；顶部继续 `k/↑` 补载上一页。滚轮和 PgUp/PgDn 也支持。每次操作至多启动一个分页请求。
- 串内长楼层先逐行读完，最后一个展开引用也计入边界。读到末尾继续 `j/↓` 才加载下一页；顶部 `k/↑` 加载上一页。向上跨页落在上一楼尾部。`n/p` 保留直接跳楼语义，并可跨页。
- 空格、PgUp/PgDn、Ctrl+U/D 和鼠标滚轮在串内滚动到边界后也能触发加载。请求期间复用 busy 状态，不重复请求；Esc 取消，旧请求结果受 requestID 检查约束。
- 已有内容保留，新增帖子按编号去重。前插内容时校正阅读偏移、楼层选择和展开引用。列表有本地筛选或页内最新排序时暂停自动加载，避免扫描远端寻找匹配项或改变排序中的位置；手动翻页和跳页仍可用。
- 每个帖子记录其来源页及页内位置。当前页、楼层编号、历史和收藏的阅读页码跟随选中的帖子，而非最后下载的页。按 P 或 [ ] 跳转会替换当前连续加载区间；重新打开仍按保存页码和帖子锚点恢复。

## 页码窗口

`P` 打开，直接输入页码，Enter 跳转，Esc 取消。当前页显示在输入框上方；`:` 继续用于帖子编号定位。

页码范围为 1—1000000；已知总页数时再限制为 1—总页数。岛民岛按 count/size 计算，X 主串按主楼回复数及适配器的 19 条回复一页计算。X 列表和 BOG 没有可靠总数时显示“总页数未知”，不把分页导航窗口误当成末页。

- `Ctrl+Home`：首页。
- `Ctrl+End`：已知总页数时到末页。
- `Ctrl+L`：串内且总页数已知时，到末页最新回复。
- `[ / ]`：继续保留直接上一页/下一页，按当前选中帖子的页码计算。

## 失败和验证

自动加载失败保留列表/正文/光标，暂停该页自动重试，用 [ ] 或 P 显式重试。返回空页时停止该方向，不因错误 hasMore 而无限请求。跳转到空的非首页、返回页码不匹配或其他读取失败，均保留原内容与阅读位置。HTTP 读取不触发发帖或附件上传。

测试覆盖长回复与嵌套引用读完才跨页、前插长回复、列表跨页去重、在途重复按键、页码上下界、未知总数、末页最新回复、错误/空页/取消后的迟到响应、鼠标和正文滚动键、跨页楼层与阅读记录，以及 44×16 的跳页窗口。


## v0.0.11：居中列表与下一页预取

列表按实际卡片高度计算行偏移，选中卡片尽量保持在可用区域中间；到达头尾时夹紧偏移。滚动采用与串内阅读相同的 150ms 动画，新输入从当前可见位置接续，鼠标按当前动画帧命中卡片。

列表和当前串分别保留一个下一页预取槽。当前页有下一页时，在后台请求当前页加一；结果仅存于会话内存，用户跨页前不修改可见内容、光标或页码。命中缓存则复用原有去重拼接流程；请求仍在进行时合并等待，不发重复请求，不锁定输入。等待期间若用户离开原位置，完成时仅保留缓存，不自动跳转。

预取使用独立请求与窗口标识。切板块、切岛、重载和退出时取消失效请求，迟到结果不进入新窗口。空页终止该方向加载；预取失败不循环重试，用户可通过现有翻页操作重试。本地筛选与页内最新排序时暂停列表预取。已有上一页继续复用已加载窗口，不额外预取上一页。


## 半页提前接入

在 v0.0.11 预取的基础上，不再等到已加载页尾才接入缓存。选中项到达当前服务端页面后半段（从零计数的索引达到条目数除以二）时，将准备好的下一页去重追加到列表或串末尾。请求仍可提前发出；响应较晚时，以收到响应时的选择位置判断是否接入。

接入不改变选中串、楼层、展开引用、当前页码或画面偏移。列表不重新筛选，串内不自动换楼，正在运行的滚动动画保留帧与目标位置。后续向下移动时，因为原页尾下方已有内容，继续使用正常居中规则。长回复仍逐行阅读，嵌套引用按所在主楼层判断半页位置。

始终只请求选中页的下一页；追加完成本身不会触发再下一页请求。只有光标进入新页后才预取它的下一页，到新页后半段再接入。已知末页不再请求；网络未完成时允许继续浏览已有内容，到真实末尾仍可能等待。筛选、页内排序、弹窗、忙碌期间暂停接入；用户移回前半页时响应只留缓存。沿用窗口标识、取消、错误和空页保护。
