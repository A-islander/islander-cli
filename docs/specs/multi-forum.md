# 多论坛适配 spec

日期：2026-09-07。基线：v0.0.1；分支：`feat/multi-forum-adapters`。

## 目标与本次交付

让现有 Bubble Tea TUI 和 Cobra CLI 通过同一组论坛操作浏览岛民岛、X 岛和 BOG。保留现有阅读光标、原位嵌套引用、附件预览与文件选择器，不重写界面。

本次实现第一阶段：三站浏览、显式站点选择、独立身份与草稿存储、能力查询。岛民岛现有发布、上传、我的内容和管理操作保持可用。外站写操作属于第二阶段，本分支不调用，也不把未实现的接口报告为可用。

| 功能 | 岛民岛 | X 岛 | BOG |
| --- | --- | --- | --- |
| 板块、时间线、逐页读串 | JSON | JSON | 网页结构解析 |
| 按编号读帖、嵌套引用 | JSON | JSON `/ref` | JSON `/api/thread/ID` |
| 图片元数据、终端预览、下载 | 支持 | 支持 | 支持 |
| 饼干导入、按站点存储 | 服务端验证 | 受限板块只读验证 | 保存网页饼干，明确未验证 |
| 发串、回复、附件上传 | 保留 | 第二阶段 | 第二阶段 |
| 我的内容、SAGE、删除恢复、领取饼干 | 保留 | 不支持 | 不支持 |

## 接口与数据

`forum.Backend` 组合只读接口、身份接口和写接口；具体适配器封装各自 HTTP 协议。`Capabilities` 显式说明当前适配器实现的能力；不可用操作返回 `unsupported`，不能返回空列表或成功。CLI 增加 `site list` / `site info` 和全局 `--site islander|x|bog`。

BOG 网页板块使用名称作为 key，生成稳定的本地导航 id；这个 id 不作为 BOG 数字 API 的 forum 参数。CLI `--board` 可接受返回的导航 id 或板块名称。

统一的 Post 保留旧 JSON 字段，新增来源、公开作者标识、原始 HTML、父串未知标记。作者的公开 hash 仅供显示，不能替代可验证用户 ID，也不能用于判断所有权。附件统一为 Media。HTML 实体和换行转为正文，去除脚本、样式及终端控制字符；原始 HTML 仅作为数据保留，不直接呈现。

CLI JSON 顶层增加 site 来源字段，旧 schemaVersion/data 保留。

Page 保留 page/size/list/hasMore；外站读串增加 root 元数据，供后续页保留主楼上下文而不重复插入列表。未知 count 为 -1；未知楼层偏移为 -1。TUI 根据 hasMore 前进，不再按固定 20 条推算所有站点页数或楼层。外站主楼仅在第一页列入返回列表；引用查询不能确定父串时明确标记，不把引用当作可直接打开的主串。可在已知主串上下文中逐页定位回复，设置扫描上限并支持取消。

编号只在当前站点实例内有效。每次切站取消旧请求，递增请求代号并清空帖子、分页、引用、光标和滚动位置；旧异步结果必须丢弃。第一阶段切回站点从第一页重新加载，不保存跨站阅读历史。

## 身份、兼容与交互

默认站点仍是岛民岛；原有命令、安装路径、模块名不变。现有岛民岛 URL 对的存储哈希算法保持不变，旧饼干和草稿无需搬迁。外站将站点标识及规范化 endpoint 加入存储作用域，相同别名互不共享。CLI 默认匿名，带 `--cookie` 才加载身份；TUI 仅加载所选站点的活动身份。

外站不复用岛民岛 Authorization。X 饼干作为原样 `userhash` Cookie；BOG 接受 `bog_master` / `bog_sel`（可选 `bog_list`）的 Cookie 字符串，仅发到选定的 BOG endpoint。拒绝 Cookie 换行和注入、拒绝携带凭证跟随重定向。媒体请求不附加论坛凭证。错误不回显凭证。

TUI 按 `g` 选择站点，标题持续显示当前站点。外站操作菜单仅展示已实现动作；我的内容按钮在不支持时显示站点切换入口。按不支持的快捷键提供明确提示。帮助内容与当前能力一致。默认三站 endpoint 可直接使用，`--forum-url` 可显式覆盖；`--user-url` 只适用于岛民岛，避免误以为外站使用其身份服务。

## 协议依据与第二阶段

X 使用 `getForumList`、`timeline`、`showf`、`thread`、`ref` 和 `getCDNPath`。数字兼容字符串，过滤 Tips 系统提示；识别 HTTP 200 中的业务错误。依据：[X 客户端作者整理的 API](https://github.com/TransparentLC/xdcmd/wiki/自己整理的-X-岛匿名版-API-文档)。

BOG 使用公开网页 `/f/板块名/页码`、`/t/串号/页码`，按 DOM 结构提取帖子、板块和下一页；引用 JSON 成功码为 6001。缺失必需结构视为格式变化，不能伪装成空页。依据：[官方时间线](https://bog.ac/f/时间线)、[官方 API 入口](https://bog.ac/page/api)、[站点脚本](https://bog.ac/static/js/script.js?20230911:2)。API 文档托管当前无法取得完整内容，因此不猜测列表 API2 路由。

第二阶段独立实现外站发布事务：X 表单和图片可同次 multipart 提交，需要当前表单隐藏字段；BOG 上传与发帖分开，成功码也不同。届时由适配器拥有上传及提交顺序，通用层只负责草稿持久化、站点/身份/目标绑定的预览确认、成功标记和不自动重试。需分别确认站点字数、图片数、权限、验证码、发帖间隔、成功判定；不得套用岛民岛规则。BOG 未提供可验证账户的凭证时，不能宣称验证了认证与实际发布。

## 验收

- 原有 Go 测试、竞态测试、vet 通过，岛民岛发布预览与身份绑定回归通过。
- 适配器本地 HTTP fixture 覆盖三站响应、业务错误、HTML 换行/颜文字/引用/图片、分页与格式变化。
- 身份存储隔离；外站不发送 Authorization；拒绝重定向泄露；不支持的操作不产生网络请求。
- TUI 切站丢弃旧响应和缓存，未知总数可以翻页，嵌套引用不跨站串号混淆。
- 实际三站只读 smoke：板块、列表、主串、引用；X 使用已有饼干验证受限板块读取。真实凭证不进入测试代码、日志或仓库。
- 提供本地构建和试用命令；本分支不自动发帖、不自动合并或发布新版本。

## 本次验证记录

2026-09-07：三站匿名只读 smoke 成功。岛民岛返回 6 个板块、20 条时间线内容；X 岛返回 61 个板块、20 条时间线内容；BOG 返回 17 个板块、20 条时间线内容。X 岛主串 50000002 的第 1/2 页分别为 20/19 条（第一页含主楼）；BOG 主串 1423209 为 21/1 条，第 2 页 hasMore=false，均未重复主楼。

X 饼干经过新 CLI 的隐藏 stdin 导入流程验证，AI 板 27 和故事板 19 均成功读取 20 条，并完成带凭证的引用读取。验证使用临时隔离的本地数据目录，结束后删除；未向任何论坛发帖。BOG 没有进行真实账户验证，界面与元数据继续标记未验证。

自动检查：`go test -race ./...`、`go vet ./...` 和 `git diff --check` 均通过。覆盖切站时丢弃旧响应、重置光标与引用、同名饼干和草稿隔离、未知总数翻页、外站能力限制，以及原有岛民岛发布流程回归。本地试用程序为 `bin/islander-dev`，构建版本标记 `v0.0.1-multiforum-dev`，未生成新发布版本。

## 串预览补充

三站共用只读串分页接口，为宽屏当前选中串自动加载第一页并预览最多五条回复。选中停留 180ms 后发起请求，预览请求有独立取消和代号，不阻塞选串，不覆盖完整阅读分页；切串、刷新、切身份和切站后丢弃旧响应。当前列表代次缓存成功结果和错误，Ctrl+R 可重新读取。个人内容中的单条回复不作为主串查询。

预览压缩正文长度，显示回复摘要和更多内容提示；实际标题与自动生成的列表摘要分开，避免无标题长文在阅读区重复显示。预览从开头显示，完整阅读的位置单独保留。

## TUI 内附件查看

附件列表 Enter 直接打开内嵌图片窗口，支持左右切图、Esc 返回列表及保留原帖阅读位置、r 重试、b 字符回退、o 外部打开和 s 下载。异步下载与图片解码不阻塞界面，迟到结果按独立图片 ID 丢弃。保留 20 MB / 3200 万像素的输入限制，只保留当前图片的缩放数据。PNG/JPEG/GIF 首帧支持；视频、音频和其他格式显示外部打开入口。

Auto 模式查询终端 Kitty 能力，确认后通过 Bubble Tea Raw 发送有编号的虚拟图片 placement，TUI 正常绘制 Unicode 图片占位符；不直接改写终端光标或启动图片子进程。上传也等待确认，查询或上传超时回退为彩色半块字符图。窗口缩放替换同一 placement，关闭/切图仅删除当前图片 ID。协议依据：[Kitty Unicode placeholders](https://sw.kovidgoyal.net/kitty/graphics-protocol/#unicode-placeholders)、[Ghostty 图形能力](https://ghostty.org/docs/features)。

附件验证：HTTP 图片解码/尺寸限制、透明背景和比例、原生占位符经 TUI 合成后保留编号颜色、迟到响应丢弃、取消/返回、协议超时回退及三种窗口尺寸测试通过。另用本地 HTTP 服务和 PTY 模拟终端协议应答，验证进入帖子、打开附件、图片下载、原生虚拟 placement 传输、占位符绘制、返回和退出的完整流程；未在真实 Ghostty 图形窗口中进行目视验收。`go test -race ./...`、`go vet ./...` 通过，两个本地可执行文件已同步。
