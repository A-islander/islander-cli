# 长回复阅读与颜文字选择

日期：2026-09-07。基线 `main` / v0.0.3，开发分支 `feat/reader-scroll-kaomoji`，首发版本 v0.0.4。

## 阅读行为

原先 `j/k` 和上下键直接选中相邻帖子，超过一屏的回复会在读完之前被跳过。现在每个渲染条目记录自身正文的起止行，范围包含标题、附件提示、引用展开提示，不包含子引用及楼间分隔线。

- `j` / `↓`：当前条目底部仍在屏外时只下滚一行；底部完整可见后，下一次按键选中下一条。短帖保持快速换楼。
- `k` / `↑`：当前条目头部仍在屏外时只上滚一行；回到条目头部后再选上一条。上一条很长时从其尾部进入，继续向上读。
- 原位展开的引用使用同一规则，选择不会在滚动途中跳到下一条引用；最末长回复读到底后不会跳回开头。
- `n/p` 仍直接跳原串下一楼 / 上一楼；`PgUp/PgDn`、空格仍用于快速滚动。窗口宽度变化后按重新排版的条目范围判断。
- 滚动期间保留当前帖子/引用的选择、操作目标及阅读位置自动保存逻辑，列表里的 `j/k` 仍用于选串。

## 颜文字选择

编辑页常驻 `F3 颜文字` 提示。F3 打开 99 个颜文字，每行四个，按原顺序向下排列，无分类、无逐项说明。方向键或 hjkl 按网格移动（上下跨四项），Tab/Shift+Tab 选择下一项/上一项，Home/End 到首尾，Enter 插入，Esc/F3 返回编辑。选择器只处理自己的按键，不将 j/k 等导航键输入草稿。

打开前保存当前草稿，保留正文和标题光标、焦点及选区；返回时不重新 SetValue。颜文字插入当前编辑字段，正文有选区时按粘贴行为替换选区。插入后进入既有自动保存和编辑历史流程；取消不改变文本或光标。Ctrl+C 保存草稿后退出。

岛民岛和 X 岛直接复制 `islander-vue-web/src/assets/emoji.ts`，已核对与 Flutter 的 `lib/core/constants/emoji_constants.dart` 内容及顺序一致；BOG 直接复制 `islander-vue-web/src/assets/emoji_bog.ts`，保留其特殊括号写法，不以机械替换生成。预览与实际插入使用同一目录。其他 Unicode 字符（包括 `ﾟ`）原样保存与插入，只有显示层继续使用既有的宽度兼容替换。不改写用户已输入的正文或历史草稿。插入前校验正文/标题余量，不截断颜文字；容量不足时留在选择器并提示。窄窗口仍保持四列，格内过长内容省略，网格下方显示当前选中的完整颜文字；按可见行数滚动网格，保持插入和返回操作提示可见。

该功能为本地编辑辅助，三站共用，不读取系统剪贴板或触发上传、回复、发帖。目录和最近选择暂保存在程序中；不增加个人收藏颜文字或跨进程最近使用记录。

## 验证

交互测试覆盖宽/窄终端的长回复、长引用逐行阅读与反向返回、最后一条边界、n/p 直接跳楼及缩放。颜文字测试覆盖三站正文中间插入、取消后光标不变、标题焦点、四列布局、网格导航、BOG 特殊条目、自动保存、长度边界和 44×16 至 120×36 的终端宽度与按键提示。
