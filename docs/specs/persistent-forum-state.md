# TUI 状态持久化

日期：2026-09-07；基线 `main` / v0.0.2，首发版本 v0.0.3，开发分支 `feat/persistent-forum-state`。

## 范围

本分支为 TUI 增加最后站点、每站每身份的导航与阅读恢复、浏览历史、本地收藏，以及草稿自动保存和有限编辑快照。普通 CLI 的默认站点仍为岛民岛；只有未指定站点或 endpoint 的 `tui` 入口恢复最后站点。显式 `--site` / `--forum-url` / `--user-url` 优先，`--demo` 不记录浏览状态。

v0.0.3 包含下述新增能力。本次不修改 Flutter、不重新发布旧版本。

## 文件位置与兼容

默认根目录由 Go `os.UserConfigDir()` 决定：Linux 为 `$XDG_CONFIG_HOME/islander`，未设置时 `~/.config/islander`；macOS 为 `~/Library/Application Support/islander`；Windows 为 `%AppData%/islander`。`--data-dir` 覆盖整个根目录。

```text
islander/
  preferences.json                 # version=1，lastSite 和最近使用的各站 endpoint
  <原有站点/endpoint 哈希>/
    cookies.json                   # 原有身份元数据
    browsing.json                  # version=1，按匿名/饼干别名分组 session/history/favorites
    draft-<id>.json                # 原有草稿字段 + editHistoryVersion=1 + editHistory
```

凭证仍使用系统密钥环或用户显式选择的原有 file 后端。新文件没有 Cookie/token。现有岛民岛作用域哈希不变，原来的草稿文件可直接读取；草稿编辑记录嵌入同一个 JSON，使当前稿和快照通过一次原子替换一起落盘。JSON 写入用 0600 权限，Windows 的文件访问控制仍遵循系统 ACL。

写前取得对应文件锁，重新读取磁盘内容再合并当前身份的数据，避免一个窗口覆盖其他岛/身份。锁冲突及损坏文件显示错误，未知版本和非法 JSON 保留原文件，不用空状态覆盖。相同身份同时操作同一导航状态时以最后成功写入为准；本版不实现多窗口协同编辑。

## 站点、会话和阅读

- TUI 成功激活站点配置后即保存最后站点，不依赖联网成功；下次启动恢复最近 endpoint。每种站点保存一个最近配置，自定义实例的内容状态仍按 endpoint 分目录。
- 每岛按匿名身份或饼干别名保存板块 key/ID、列表页、选中串、筛选、页内排序以及当前主串。
- 阅读位置保存主串 ID、页码、主串内帖子 ID、该帖子内滚动比例。引用展开状态不持久化，从历史或收藏续读时恢复到所属的原串楼层。
- `preferences.json` 的 `agentSimulation` 保存界面模式，缺省为 false。启动沿用上次模式；两种模式均保持列表焦点，Agent 模式在后台预加载第一条，普通模式在宽屏右栏预加载第一条。模式写入不替换已保存的站点配置。
- 启动先读板块和当前岛时间线第 1 页，选中第一条，从该串第 1 页展示；不自动恢复原板块、列表页、筛选、排序或最后浏览的串。首页自动加载第一条时跳过旧阅读位置；历史、收藏及之后手动选择仍可续读。手动恢复楼层优先读取保存页；楼层不在该页时最多检查前后相邻各一页，不调用全串扫描。读页失败或原页已无内容可回退串首页；仍不可访问时显示失败且保留原持久状态。
- 读取成功后按帖子 ID 定位并应用相对滚动量，不依赖旧窗口的绝对像素/行号。板块已移除则退回该岛时间线。
- 导航改变后 500ms 合并保存，离开页面、切岛、切身份、退出和终端报告失焦时补保存。切换会话后旧 timer / 请求不能向新作用域落盘。

## 浏览历史

`H` 打开当前岛、当前身份的历史；`/` 按标题或串号筛选；Enter 恢复阅读；`x` 删除选中记录。菜单提供清空及暂停/启用记录。删除、清空需确认，草稿不受影响。切岛后可用同一个入口查看该岛历史。

只有完整读串成功后记历史，列表预览不计入。按主串 ID 合并，最多 500 条、保留最近 90 天，标题摘要最多 160 字符，不保存全文和图片。时间及阅读锚点随阅读更新；同一串翻页不会生成重复条目。

清空或删除记录推进删除时间界限；之前开始的阅读会话及延迟保存不能立刻把记录补回来，重新主动读取该串才形成新访问。暂停记录保留已有历史，但不再保存新的串与楼层足迹；仍记住所选岛与板块。

## 收藏与长串续读

- `*` 收藏 / 取消收藏当前主串，`F` 打开收藏页，`/` 筛选标题或串号，Enter 续读，`x` 确认取消收藏。帖子操作菜单也提供入口，底部显示快捷键，已收藏串显示 `★`。即使选中串内回复或嵌套引用，收藏目标也是当前主串；在“我的内容”列表选中回复时保存其所属主串 ID。
- `Browsing.favorites` 使用与历史相同的 `HistoryEntry`，按站点 endpoint 和身份隔离；保存主串 ID、标题摘要、列表上下文及阅读锚点，不保存正文或媒体。兼容旧 version=1 文件，缺失字段视为空收藏。
- 收藏为用户显式选择，永久保留直到取消。收藏预览只保存串入口，不凭预览页码生成足迹。完整阅读成功后的保存同时更新已有收藏的进度；普通串随历史的 90 天 / 500 条限制淘汰，已收藏串的锚点独立保留。
- 普通列表 Enter、主串编号定位、收藏和历史入口均支持续读；按回复编号定位仍优先打开指定回复。从列表续读只读取保存的串页，不重新跳回收藏时的列表；收藏和历史恢复保存的列表上下文。
- 清空 / 删除历史同步清除对应收藏的页码和锚点，但保留收藏项。暂停历史也暂停更新收藏锚点；已有记录仍可用于恢复。取消收藏不会删历史，旧自动保存不能重新创建已取消收藏。
- 收藏在本地文件中完成，三个站点都能使用，不依赖服务端收藏接口或发帖权限。

## 终端图片

`a` 直接打开当前选中帖子或引用的首张附件，`←` / `→` 切换，Esc 回原帖，保留页码、选中楼层和滚动位置。复用现有图片预览：`--images auto` 查询 Kitty 图形协议，确认支持后在当前 TUI 内显示原图，否则回退彩色字符预览；`kitty / blocks / off` 可手动指定。未接入 Sixel 或 iTerm2 独立图片协议；`o` 外部打开、`s` 下载仍可使用。这里只在打开附件时下载图片，不自动下载整页媒体。

## 编辑与恢复

- 编辑变化后 350ms 自动保存；退出编辑、预览发布、进入文件选择器和支持的终端失焦事件会补保存。
- `F2` 打开编辑历史，Enter 把所选版本恢复为当前草稿并形成新的检查点，Esc 返回编辑。恢复不会发帖。
- 保留最近 20 个不同内容快照；自动保存最多每 30 秒形成一个检查点，手动保存、离开编辑和打开历史时立即形成检查点，相同内容不重复添加。
- 草稿仍绑定原站目录、饼干别名及板块/回复目标；恢复不迁移目标或身份。正文为空的未完成草稿可以保存，发布时仍执行原有完整校验。
- 历史只保存附件路径和已上传媒体引用，不复制附件文件。源文件移除后需要重新选择，发布前的原有文件校验会阻止静默漏传。该功能不提供附件备份。
- 发布成功删除当前稿及其快照；若删除失败则保留 sent 标记，拒绝自动保存把它改回待发草稿。草稿删除后，旧编辑 timer 不得重新创建文件。

## 验证

存储测试覆盖版本/损坏保护、身份与站点隔离、历史保留上限、删除时间界限、草稿旧格式兼容和编辑快照上限。Cobra 测试验证只有未指定站点的 TUI 恢复偏好，显式参数、普通 CLI 和 demo 行为稳定。

TUI 测试覆盖三站导航/阅读恢复、有限相邻页查找、预览不记历史、跨站 timer 丢弃、输入自动保存、F2 恢复及清空历史不删草稿。使用本机 HTTP fixture 和真实 PTY 进行退出/重启验证，无生产发帖或真实饼干访问。

新增验收覆盖三岛从普通列表和收藏重开第 42 页、保留楼层滚动量、收藏筛选与取消、收藏超过历史保留期仍可续读、暂停与清除锚点、身份/endpoint 隔离；图片直开、左右切换和 Esc 返回由交互测试验证，原有原图协议确认/回退/缩放测试继续运行。
