Islander v0.0.9 将首次启动 TUI 的默认站点改为 X 岛，直接加载时间线及第一条串的内容。

- 没有已保存站点偏好时，运行 `islander tui` 默认进入 X 岛；已有用户继续使用上次访问的站点。
- 显式指定 `--site` 或自定义接口地址时沿用指定配置；演示模式不受影响。
- 普通 CLI 命令的默认站点仍为岛民岛，现有脚本无需调整。
- 更新启动偏好说明，并覆盖首次启动、已保存偏好及显式参数的回归测试。

已有饼干、草稿、收藏、浏览历史、图片缓存和界面偏好保持兼容，无需迁移。

安装或更新：

```sh
go install github.com/A-islander/islander-cli/cmd/islander@v0.0.9
islander --version
islander tui
```

| 系统 | 架构 | 格式 |
| --- | --- | --- |
| Linux | x86_64 / aarch64 | tar.gz、AppImage |
| macOS | Intel x86_64 / Apple Silicon aarch64 | tar.gz、DMG |
| Windows | x86_64 / aarch64 | ZIP、独立 EXE |

共 12 个带版本号的安装包及 SHA256SUMS。macOS DMG 内的 Islander.app 在 Terminal 中启动 TUI；macOS 包未做 Developer ID 签名或公证，Windows EXE 未做 Authenticode 签名。

Windows x86_64（普通 Intel / AMD 64 位电脑）：[下载 EXE](https://github.com/A-islander/islander-cli/releases/download/v0.0.9/islander-v0.0.9-windows-x86_64.exe) / [下载 ZIP](https://github.com/A-islander/islander-cli/releases/download/v0.0.9/islander-v0.0.9-windows-x86_64.zip)。

```powershell
.\islander-v0.0.9-windows-x86_64.exe tui
# ZIP 解压后：
.\islander.exe tui
```
