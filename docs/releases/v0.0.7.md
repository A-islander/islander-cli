Islander v0.0.7 改进首页启动、Agent 模拟导航和逐楼阅读，补充板块快捷键与图片滚轮缩放。

- 启动固定进入当前岛的时间线第 1 页，选中第一条，从串首页预加载；保持列表焦点，不再自动跳进上次浏览的串。历史、收藏和长串阅读位置保留，手动打开时仍可继续阅读。
- 记住上次使用的论坛 / Agent 模式。F6 切换保留列表或阅读焦点；Agent 列表的标题、摘要及模拟读取文字均可单击进入串。阅读页右上角增加无边框 `exit`，点击返回串列表，保留列表与阅读位置并复用缓存。
- 普通布局单击帖子标题直接进入阅读，无标题时点击首行正文；菜单打开后再次右键或点击外部关闭，关闭动作不会穿透到下层控件。
- 串内滚轮、j/k 和上下键按楼层移动，普通回复以约 150 ms 的动画平滑居中；串头、串尾按内容边界停靠，超长回复和嵌套引用逐行读完后再换楼。PgUp/PgDn、空格、n/p 保留快速浏览方式，边界继续自动翻页。
- 动画只改变显示位置，不逐帧请求接口、下载图片或写入历史；连续滚动平滑衔接，动画途中鼠标命中以当前可见位置为准。
- Ctrl+[ / Ctrl+] 切换当前岛的上一个 / 下一个板块，包含时间线，到两端停止。终端需支持按键消歧义；Ctrl+[ 被识别成 Esc 时可用 b 选择板块。
- 原图浏览窗口内滚轮向上放大、向下缩小，复用已加载图片；+/- 缩放和 0 适应窗口继续可用。串内小图可点击进入原图浏览，不支持原生图片协议时保留附件入口与字符预览。

已有饼干、草稿、收藏和历史文件保持兼容，无需迁移。界面模式保存在 preferences.json 中。

安装或更新：

```sh
go install github.com/A-islander/islander-cli/cmd/islander@v0.0.7
islander --version
islander tui
```

| 系统 | 架构 | 格式 |
| --- | --- | --- |
| Linux | x86_64 / aarch64 | tar.gz、AppImage |
| macOS | Intel x86_64 / Apple Silicon aarch64 | tar.gz、DMG |
| Windows | x86_64 / aarch64 | ZIP、独立 EXE |

共 12 个带版本号的安装包及 SHA256SUMS。macOS DMG 内的 Islander.app 在 Terminal 中启动 TUI；macOS 包未做 Developer ID 签名或公证，Windows EXE 未做 Authenticode 签名。

Windows x86_64（普通 Intel / AMD 64 位电脑）：[下载 EXE](https://github.com/A-islander/islander-cli/releases/download/v0.0.7/islander-v0.0.7-windows-x86_64.exe) / [下载 ZIP](https://github.com/A-islander/islander-cli/releases/download/v0.0.7/islander-v0.0.7-windows-x86_64.zip)。

```powershell
.\islander-v0.0.7-windows-x86_64.exe tui
# ZIP 解压后：
.\islander.exe tui
```
