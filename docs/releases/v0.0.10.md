Islander v0.0.10 新增 el 主题，让 TUI 柔和适配终端的前景色与背景色。

- 使用 `islander tui --theme el` 开启适配，`--theme islander` 本次使用原主题；F7 在两者之间切换并保存选择。
- 保留终端背景，柔化高饱和度正文，并协调选中行、边框、编辑框及 Agent 模式的命令配色和 Working 动画。图片保持原色。
- 异步查询终端颜色，不阻塞论坛加载；终端或 tmux 未返回完整颜色时保留原主题。深色、浅色与中等亮度背景均调整文字和选中项的对比度。
- 主题与 Agent 模式分别记忆，切岛保留当前主题；已保存的原型主题名 `terminal` 兼容读取为 `el`。
- 更新 README 和终端主题 spec，覆盖配色、图片编码保留、阅读状态与偏好恢复的回归测试。

已有饼干、草稿、收藏、浏览历史、图片缓存和界面偏好保持兼容，无需迁移。

安装或更新：

```sh
go install github.com/A-islander/islander-cli/cmd/islander@v0.0.10
islander --version
islander tui --theme el
```

| 系统 | 架构 | 格式 |
| --- | --- | --- |
| Linux | x86_64 / aarch64 | tar.gz、AppImage |
| macOS | Intel x86_64 / Apple Silicon aarch64 | tar.gz、DMG |
| Windows | x86_64 / aarch64 | ZIP、独立 EXE |

共 12 个带版本号的安装包及 SHA256SUMS。macOS DMG 内的 Islander.app 在 Terminal 中启动 TUI；macOS 包未做 Developer ID 签名或公证，Windows EXE 未做 Authenticode 签名。

Windows x86_64（普通 Intel / AMD 64 位电脑）：[下载 EXE](https://github.com/A-islander/islander-cli/releases/download/v0.0.10/islander-v0.0.10-windows-x86_64.exe) / [下载 ZIP](https://github.com/A-islander/islander-cli/releases/download/v0.0.10/islander-v0.0.10-windows-x86_64.zip)。

```powershell
.\islander-v0.0.10-windows-x86_64.exe tui
# ZIP 解压后：
.\islander.exe tui
```
