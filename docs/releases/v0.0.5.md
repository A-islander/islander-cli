Islander v0.0.5 加入三岛图片预览、tmux 图片透传，以及小图和原图缩放。

- 岛民岛、X 岛、BOG 的串预览、正文和原位展开的引用均支持小图。串预览把首张小图放在正文旁边，默认保留五条短回复；进入串后多图依次排列。
- 终端支持图片时才自动加载，优先使用站点缩略图，只请求阅读位置附近的图片，并限制并发与内存缓存。未确认支持时只显示 `a 加载附件`，按下后才下载，附件窗口可降级字符预览。
- `+` / `=` 放大、`-` 缩小串内小图，复用已加载的图片。列表预览中的 `a` 同时包含主楼与预览回复的附件；阅读时仍针对当前楼层或引用。
- 原图窗口也支持 `+` / `=`、`-` 缩放，`0` 恢复适应窗口；`Shift + 方向键` 移动放大后的画面，`↑↓` 也可上下移动。普通左右键仍切换附件，Esc 返回并保留阅读位置。
- Ghostty / Kitty 配合单层 tmux 时自动使用图片透传，临时为当前窗格启用 `allow-passthrough`，退出恢复原设置；不修改全局或磁盘配置。其他兼容终端可显式使用 `--images kitty`。

GIF 显示首帧，视频和音频仍使用外部应用。自动识别通过 tmux 客户端名称判断兼容性；若外层终端自行关闭了图片能力或使用嵌套 tmux，可用 `--images blocks` 保留按 `a` 打开字符预览的方式。

安装或更新：

```sh
go install github.com/A-islander/islander-cli/cmd/islander@v0.0.5
islander --version
islander tui
```

| 系统 | 架构 | 格式 |
| --- | --- | --- |
| Linux | x86_64 / aarch64 | tar.gz、AppImage |
| macOS | Intel x86_64 / Apple Silicon aarch64 | tar.gz、DMG |
| Windows | x86_64 / aarch64 | ZIP、独立 EXE |

全部 12 个包带版本号，并提供 `SHA256SUMS`。macOS DMG 内的 Islander.app 在 Terminal 中启动 TUI；macOS 包未做 Developer ID 签名或公证，Windows EXE 未做 Authenticode 签名。

现有饼干、草稿、收藏及阅读位置继续兼容，无需迁移。图片缓存与缩放级别只保存在本次运行内存中。
