Islander v0.0.8 为串内小图和原图增加持久化磁盘缓存，换串、切岛或重启后无需重复下载已缓存的图片。

- 小图和原图共用按完整 URL 区分的源文件缓存；同一 URL 只需下载一次，不会用低分辨率缩略图替代原图。不同 URL 分别缓存。
- 默认上限 256 MiB / 1024 张，写入时清理 30 天未使用的图片，并按最近使用时间淘汰。缓存命中无需联网；损坏条目会重新获取。
- 同时读取同一 URL 时合并下载，取消一个读取者不影响其他等待者；磁盘不可写或缓存忙碌时仍可正常显示下载成功的图片。
- 原图页按 r / Enter 强制刷新，成功后更新缓存，失败保留之前可用的缓存。关闭原图或退出 TUI 只清理终端显示与内存，不删除磁盘图片。
- 保留无饼干的媒体下载方式以及文件大小、图片尺寸和解码校验；失败响应与非图片内容不写入缓存。

默认缓存目录：Linux 为 $XDG_CACHE_HOME/islander/images（通常 ~/.cache/islander/images），macOS 为 ~/Library/Caches/islander/images，Windows 为 %LOCALAPPDATA%\islander\images。指定 --data-dir 时使用该目录下的 cache/images。删除缓存目录即可清空，下次浏览时自动重建。

已有饼干、草稿、收藏、浏览历史和界面偏好保持兼容，无需迁移。

安装或更新：

```sh
go install github.com/A-islander/islander-cli/cmd/islander@v0.0.8
islander --version
islander tui
```
