Islander v0.0.2 支持在同一个终端客户端浏览岛民岛、X 岛和 BOG。

- TUI 按 `g` 切站、`b` 选板块；CLI 使用 `--site islander|x|bog`。各站饼干和草稿独立存储。
- 宽屏串预览自动展示主楼及最多五条回复摘要；修复长正文重复、预览阅读位置及板块快捷键提示。
- 附件可直接在 TUI 内查看，支持切图、重试和返回原帖。支持 Kitty 图形协议的终端使用原生图片，不支持时回退为彩色字符图；视频等附件仍可外部打开。
- 保留岛民岛发串、回复、原位嵌套引用、我的内容、附件文件选择器和管理操作。X 岛 / BOG 本版仅接入浏览，未接入发帖和管理；BOG 饼干保存后仍标记为未验证。

安装：

```sh
go install github.com/A-islander/islander-cli/cmd/islander@v0.0.2
islander --version
islander tui
islander --site x tui
islander --site bog tui
```

无需 Go 的发布包：

| 系统 | 架构 | 格式与启动方式 |
| --- | --- | --- |
| Linux | x86_64 / aarch64 | tar.gz 解压后 `./islander tui`；AppImage 加执行权限后直接启动 |
| macOS | Intel x86_64 / Apple Silicon aarch64 | DMG 内的 Islander.app 拖入 Applications，双击后在 Terminal 中打开 TUI；也提供 tar.gz |
| Windows | x86_64 / aarch64 | ZIP 解压后在 PowerShell 执行 `.\islander.exe tui`；也提供独立 EXE |

AppImage 是 Linux 格式。macOS 包未做 Apple Developer ID 签名或公证；Windows EXE 未做 Authenticode 签名。所有包均包含版本号；`SHA256SUMS` 提供 SHA-256 校验值。

原有岛民岛饼干和草稿路径保持兼容。外站接口限制和实现范围见仓库中的 `docs/specs/multi-forum.md`。
