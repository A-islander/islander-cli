Islander v0.0.6 改进完整串阅读与鼠标操作，新增可一键切换的 Agent 模拟界面。

- 三岛右栏直接加载完整帖子页面，展示全部本页回复与附件。左右栏切换复用已加载内容、页码、引用和阅读位置，避免 Enter、h/l 或方向键反复请求同一个串。
- 选中楼层整块底色高亮。上下移动优先在当前视口选择，短回复尽量完整展示，长回复逐行读完后再换楼。正文连续换行不额外留空，移除楼层左右标记与多余间距，站点标语并入顶栏；左侧有标题卡片四行、无标题三行。
- 鼠标支持单击选串、双击阅读、单击选楼层和右键操作菜单；滚轮跟随指针所在栏，保留边界自动翻页。板块、我的内容、菜单项、页码、引用和附件均可点击。
- 点击 `F6 Agent模拟切换` 或按 F6，进入 Codex 风格的独立对话布局。浏览时隐藏作者、串号、楼层和时间，保留真实正文与回复目标；底部回复框支持草稿、颜文字、附件和发送前预览。
- 模拟界面穿插带语法配色的 `Ran` 工具记录，同次运行内位置固定；这些是预设显示文字，不执行命令或调用 AI。进入帖子开始计时，显示 `Working (… • esc to interrupt)`，文字高光从左向右循环，动画不触发额外请求。按 F6 恢复论坛布局。

正文拖选复制仍交由终端处理。发布确认继续展示实际目标与饼干，只有确认后才发送；现有 CLI 接口、饼干、草稿、收藏和浏览状态保持兼容，无需迁移。

安装或更新：

```sh
go install github.com/A-islander/islander-cli/cmd/islander@v0.0.6
islander --version
islander tui
```

| 系统 | 架构 | 格式 |
| --- | --- | --- |
| Linux | x86_64 / aarch64 | tar.gz、AppImage |
| macOS | Intel x86_64 / Apple Silicon aarch64 | tar.gz、DMG |
| Windows | x86_64 / aarch64 | ZIP、独立 EXE |

12 个安装包均带版本号，并附 `SHA256SUMS`。macOS DMG 内的 Islander.app 在 Terminal 中启动 TUI；macOS 包未做 Developer ID 签名或公证，Windows EXE 未做 Authenticode 签名。
