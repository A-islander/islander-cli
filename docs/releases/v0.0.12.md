Islander v0.0.12 修复快速切换板块时的卡顿，并保留回复后的阅读位置。

- 连续按 `Ctrl+[` / `Ctrl+]` 切换板块时，取消旧请求并忽略迟到响应，避免旧板块的加载状态卡住新选择。终端和 tmux 仍需正确传递扩展按键。
- 回复成功后只刷新正在阅读的页，保留已加载的连续页面、选中楼层、展开引用和画面位置，不再回到第一页。
- 浏览到当前页后半段时，提前接入已预取的下一页；保持当前光标与滚动动画，跨过原页尾时继续居中阅读。网络尚未完成预取时仍可能等待。
- 鼠标滚轮按光标移动：每次前进或后退一条；`Ctrl+U/D` 按约半屏内容移动光标。超过一屏的长回复仍先逐行读完，再进入下一层。

已有饼干、草稿、收藏、浏览历史、图片缓存和界面偏好保持兼容，无需迁移。

安装或更新：

```sh
go install github.com/A-islander/islander-cli/cmd/islander@v0.0.12
islander --version
islander tui
```

| 系统 | 架构 | 格式 |
| --- | --- | --- |
| Linux | x86_64 / aarch64 | tar.gz、AppImage |
| macOS | Intel x86_64 / Apple Silicon aarch64 | tar.gz、DMG |
| Windows | x86_64 / aarch64 | ZIP、独立 EXE |

共 12 个带版本号的安装包及 SHA256SUMS。macOS DMG 内的 Islander.app 在 Terminal 中启动 TUI；macOS 包未做 Developer ID 签名或公证，Windows EXE 未做 Authenticode 签名。

Windows x86_64：[下载 EXE](https://github.com/A-islander/islander-cli/releases/download/v0.0.12/islander-v0.0.12-windows-x86_64.exe) / [下载 ZIP](https://github.com/A-islander/islander-cli/releases/download/v0.0.12/islander-v0.0.12-windows-x86_64.zip)。
