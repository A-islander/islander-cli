Islander v0.0.4 改善长串阅读，加入连续加载、页码跳转和颜文字选择器，并补齐 X 岛 / BOG 的新串发布。

- 长回复用 `j/k` 或上下键逐行读完后才换楼；原位展开的嵌套引用遵循相同规则，向上返回长楼层时从尾部继续读。
- 列表和串内读到边界后继续按键或滚动，自动追加下一页、补载上一页，按帖子编号去重。页码与阅读记录跟随当前选中的帖子，加载失败保留原内容。
- `P` 输入页码跳转，显示当前页与已知总页数。窗口内 `Ctrl+Home` 首页，已知总数时 `Ctrl+End` 末页、串内 `Ctrl+L` 最新回复；`[` / `]` 仍可手动翻页。
- 编辑页 `F3` 打开颜文字选择器：复用 Web / Flutter 的 99 个颜文字，四列排列，无分类或注释。BOG 使用 Web 的专用方括号列表，选择后插入光标处并自动保存。
- X 岛 / BOG 支持新主串：`b` 选具体板块，`c` 编辑，`Ctrl+P` 预览，Enter 确认发送。CLI `thread create` / `draft publish` 共用该流程。X 的板块编号和 BOG 网页表单中的真实板块编号分别校验。
- 列表底部补齐 `c 发串` 和 `P 跳页` 提示；没有饼干时，`c/r/R` 弹窗顶部明确提示无法发串/回复，并引导导入或选择当前岛的饼干。

外站发帖需要当前岛的有效饼干。X 最多附一张本地图片；BOG 已上传图片随草稿保留，失败后手动重试可复用。验证码、频率限制和未知提交结果沿用既有处理，不自动重发。新串流程通过真实网页只读检查和本地模拟提交验证，未向真实论坛发送测试帖。外站“我的内容”、SAGE、删除恢复、领取饼干仍未接入。

安装或更新：

```sh
go install github.com/A-islander/islander-cli/cmd/islander@v0.0.4
islander --version
islander tui
```

| 系统 | 架构 | 格式 |
| --- | --- | --- |
| Linux | x86_64 / aarch64 | tar.gz、AppImage |
| macOS | Intel x86_64 / Apple Silicon aarch64 | tar.gz、DMG |
| Windows | x86_64 / aarch64 | ZIP、独立 EXE |

全部 12 个包带版本号，并提供 `SHA256SUMS`。macOS DMG 内的 Islander.app 在 Terminal 中启动 TUI；macOS 包未做 Developer ID 签名或公证，Windows EXE 未做 Authenticode 签名。

原有饼干、草稿、历史、收藏和阅读位置继续兼容，无需迁移。自动连续加载仅保存原有的页码和帖子锚点，不将全部加载内容写入状态文件。
