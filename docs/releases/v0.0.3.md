Islander v0.0.3 增加收藏、阅读与草稿恢复，并接入 X 岛和 BOG 的回复。

- 记住上次访问的岛，按站点、endpoint 和饼干身份保存板块、页码、选中楼层及滚动位置。普通 CLI 默认站点仍为岛民岛，显式 `--site` 优先。
- `H` 打开浏览历史，`F` 打开收藏，`*` 收藏或取消当前主串；从列表、历史或收藏重开长串时继续上次阅读。普通历史保留 90 天 / 500 条，收藏及其阅读位置可长期保留。
- 草稿自动保存，`F2` 查看最近 20 个编辑快照；恢复旧稿不会自动发送。
- `a` 直接打开当前楼层或引用的图片，左右切换、Esc 返回原帖；支持 Kitty 图形协议时显示图片，否则回退彩色字符预览。
- 左上角名称和标语随岛切换：岛民岛「岛民岛的岛是岛民的岛」、X 岛「人，是会思考的芦苇」、BOG 岛「[xxx]」。
- X 岛 / BOG 支持 `r` 回复、`R` 引用回复、`Ctrl+A` 选图、`Ctrl+P` 预览后确认提交。CLI `reply create` / `draft publish` 共用该流程；新主串与外站管理功能仍未接入。

外站回复需要当前岛的有效饼干。X 一次可附一张本地图片；BOG 上传结果随草稿保留，回复失败后可手动重试。验证码需到原站完成。超时或响应不明会保留草稿并提示先核对原串，不自动重发。外站回复通过真实网页只读检查及本地模拟提交测试，尚未进行真实账户发布验证。

安装或更新：

```sh
go install github.com/A-islander/islander-cli/cmd/islander@v0.0.3
islander --version
islander tui
```

无需 Go 的发布包：

| 系统 | 架构 | 格式 |
| --- | --- | --- |
| Linux | x86_64 / aarch64 | tar.gz、AppImage |
| macOS | Intel x86_64 / Apple Silicon aarch64 | tar.gz、DMG |
| Windows | x86_64 / aarch64 | ZIP、独立 EXE |

AppImage 是 Linux 格式；macOS DMG 内的 Islander.app 在 Terminal 中启动 TUI。macOS 包未做 Apple Developer ID 签名或公证，Windows EXE 未做 Authenticode 签名。全部 12 个安装包附带版本号，并提供 `SHA256SUMS`。

原有饼干与草稿路径兼容。默认数据目录：Linux `~/.config/islander`（支持 XDG_CONFIG_HOME）、macOS `~/Library/Application Support/islander`、Windows `%AppData%/islander`。新增 `preferences.json` 保存站点偏好，各站目录的 `browsing.json` 保存历史、收藏和阅读位置；草稿文件同时保存有限编辑快照。
