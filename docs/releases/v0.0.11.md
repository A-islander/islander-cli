Islander v0.0.11 优化列表滚动、连续翻页与命令帮助。

- 帮助页每个操作一行，使用 `>` 和底色标记选项；方向键选择、Enter 查看详细说明、Esc 返回，支持鼠标与长说明滚动。
- 串列表尽量居中显示选中项，头尾按边界停靠；上下移动采用逐行滚动动画，鼠标点击按当前画面定位。
- 列表和当前串分别预取下一页，缓存命中后直接接续。后台预取不阻塞操作，不重复请求，也不会在用户移开光标后突然翻页；切换板块或站点时取消旧请求。
- 打开 `b` 板块选择时，光标对齐当前板块。
- Agent 模拟模式的回复输入区改为无边框灰底，整块区域可点击进入回复，保留文本选择显示。
- 补充帮助、列表动画、预取隔离和长回复连续阅读的回归测试，并以延迟接口验证缓存翻页。

已有饼干、草稿、收藏、浏览历史、图片缓存和界面偏好保持兼容，无需迁移。

安装或更新：

```sh
go install github.com/A-islander/islander-cli/cmd/islander@v0.0.11
islander --version
islander tui --theme el
```

| 系统 | 架构 | 格式 |
| --- | --- | --- |
| Linux | x86_64 / aarch64 | tar.gz、AppImage |
| macOS | Intel x86_64 / Apple Silicon aarch64 | tar.gz、DMG |
| Windows | x86_64 / aarch64 | ZIP、独立 EXE |

共 12 个带版本号的安装包及 SHA256SUMS。macOS DMG 内的 Islander.app 在 Terminal 中启动 TUI；macOS 包未做 Developer ID 签名或公证，Windows EXE 未做 Authenticode 签名。

Windows x86_64（普通 Intel / AMD 64 位电脑）：[下载 EXE](https://github.com/A-islander/islander-cli/releases/download/v0.0.11/islander-v0.0.11-windows-x86_64.exe) / [下载 ZIP](https://github.com/A-islander/islander-cli/releases/download/v0.0.11/islander-v0.0.11-windows-x86_64.zip)。

```powershell
.\islander-v0.0.11-windows-x86_64.exe tui
# ZIP 解压后：
.\islander.exe tui
```
